# Stack

- **Python >= 3.10**: Utilizes modern typing (e.g., `list[Symbol]`, `str | None`).
- **Stdlib Only**: The core library uses `ast`, `hashlib`, `json`, `os`, `pathlib`, `logging`, `collections.abc`, and `typing`. No runtime dependencies.
- **Tooling**:
  - `uv`: Environment management.
  - `pytest`: Test runner.
  - `mypy`: Strict type checking.
  - `ruff`: Linting and formatting.
